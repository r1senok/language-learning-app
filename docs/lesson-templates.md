# Шаблоны уроков Takku

Урок хранит порядок этапов, материалы и стабильные идентификаторы в `readerContent.ts` и тематических модулях. Lesson Reader управляет навигацией и сохраняет черновик и оценку по ID. Шаблон получает данные и callbacks, отображает состояние выбора и обратную связь. Экран, хедер, прокрутка, safe area и закреплённая нижняя панель общие для всех этапов.

| Шаблон | Где используется и что получает | Состояния и текущая реализация |
| --- | --- | --- |
| PhraseIntroduction | Часть 1, список эстонских фраз и переводов | Показ материала, переход дальше. `TheoryCard` и `AudioPhrase` используют общий `PhraseAudioButton`. |
| VocabularyAssessment | Часть 2, UUID словаря, слово, перевод и формы | «Знаю», «Учить», раскрытый перевод. `NewWordCard` использует общую нижнюю область и действующую очередь изучения. |
| MultipleChoice | Перевод фраз, перевод местоимений, выбор краткой формы и обычный выбор ответа в данных `course.ts` | Один выбранный вариант, проверка, блокировка, верный или неверный результат. `MultipleChoiceCard` поддерживает текстовый и речевой вопрос, любое число вариантов и допустимые альтернативы. |
| MatchingPairs | Сопоставление местоимений, отдельные короткие и полные формы и ID пар | Выбор с любой стороны, временная подсветка, найденные пары, завершение. `MatchingCard` и `ExerciseActionPanel`. Сохранение текущего урока учитывает исторические ID. Старый вариант `matching_pairs` в `course.ts` хранится для совместимости, его прежний механизм проверки остаётся в `ExerciseCard`. |
| TheoryReader | Местоимения, `olema` и отрицание, структурированные панели | Заголовки, абзацы, таблицы, примеры, диалоги и выделенные группы. `TheoryCard` также рендерит те же панели в `LessonReferenceSheet` для №11–12. |
| FillInBlank | Окончания и формы в №11–14, предложение с пропуском и варианты | Существующий интерфейс в `BookChoiceCard` для `book.mode: gap` и в `ExerciseCard` для исторического `fill_blank`. Допускает отдельный редизайн. |
| WordOrder | №16 и исторические задания `course.ts`, токены и порядок ID | Сборка, удаление токена, проверка, восстановление книжного черновика. Два существующих рендера используют общий `wordBank`. Компоновка подлежит отдельному редизайну. |
| LessonResult | Завершение урока, счёт, процент, лучший результат | Итог, выход, повтор. `LessonResult` и общая нижняя область. |

Шапка и действия урока используют `ReaderHeader` и `ReaderAction`. `ExerciseActionPanel` обеспечивает единую анимацию результата выбора и сопоставления. `partStarts` задаёт дополнительные экранные границы внутри этапа, а номер рассчитывается по порядку этапов и границ. Сохранённые ID и навигация между этапами от номеров в шапке независимы.

## Контракт для будущего импорта

После проверки структуры передавайте исходный порядок материалов и стабильные ID. `exerciseTemplate` сопоставляет тип упражнения с шаблоном. Книжный `multiple_choice` с `book.mode: gap` идёт в FillInBlank. Исторические строки книжного `match` служат совместимости с сохранёнными ответами. Новые пары должны приходить как `matching_pairs`. Неизвестные типы получают статус `unsupported`, Lesson Reader показывает сообщение. Book Studio и распознавание страниц на этом этапе отсутствуют.

Для выбора ответа укажите `kind: multiple_choice`, `prompt`, `options` с ID, `correct` и при наличии `accepted`. Дополнительные поля содержат инструкцию, языки, информацию об аудио и режим представления. Для перевода слов и фраз (`book.mode: translate`) по умолчанию используется `speech` с общим персонажем. Для других вопросов используется `text`. Поле `presentation` позволяет указать другой режим или ассет персонажа. Кнопка озвучки доступна при переданном обработчике. Для текущей части 3 показ правильной фразы в нижней плашке отключён в данных, чтобы сохранить её эталонный вид. Правильные карточки при ошибке подсвечиваются в обоих представлениях.

## Смысловые группы теории

`ContentGroup` отображает упорядоченный массив `panels` из блока `content-group`. Внутри могут находиться заголовки, абзацы, таблицы, примечания, примеры, диалоги и другие группы. Без `tone` заливка отсутствует. `tone: theory` использует голубую палитру Takku, `padding` принимает `none`, `compact` или `default`. У примеров заголовки `tableHeaders` переключают оформление на общую таблицу. Реплики задают сторону через `side` и могут содержать `audioSrc`.

Будущий импорт должен сохранять порядок панелей и смысловые связи, определяя группы по содержанию и роли материала на странице. Цвет или расположение сами по себе недостаточны. Неоднозначные границы нужно отправлять на ручную проверку до публикации. Визуальная выделенность исходника переводится в токен Takku. Шпаргалки с собственной привязкой к упражнениям остаются отдельными справочными блоками.

## Справочные материалы

Добавьте запись `ReferenceContent` в `lessonReferences` в `readerContent.ts` с устойчивым `id`, заголовком, списком ID упражнений `exerciseIds` и упорядоченным массивом `panels`. Один справочник можно привязать к нескольким вопросам без копирования его содержимого. `LessonReferenceSheet` показывает совпавшие записи поверх задания и передаёт панели общему `TheoryCard`, включая `ContentGroup` и `TheoryTable`. Формат списков ID и панелей совместим с предыдущими справочниками. Для импорта неочевидные связи оставляются на ручное подтверждение, прежде чем добавлять ID заданий.

## Тренировка слов

`WordStudyCard` — общий шаблон карточки для «Новых слов» в уроке и двух режимов отдельной тренировки. Прогресс урока и словарная очередь хранятся отдельно. Тренировка использует существующий словарный прогресс по стабильным ID: `0` — новое, `1` — требуется прямое направление, `2` — прямое подтверждено, `3` — оба направления подтверждены. Ошибка в обратном направлении оставляет статус `2`. Возврат выученного слова в изучение переводит его в статус `1`.

На старте подходящие ID перемешиваются один раз. Незавершённые слова в режиме «Изучение» возвращаются в конец очереди текущей сессии. Выход сохраняет уже выполненные действия. При следующем входе список формируется из актуального прогресса.

У гостя дата последней проверки хранится в существующем снимке словаря вместе со стадией. Для аккаунтов добавочная миграция `20261128000000_vocabulary_last_review.sql` расширяет существующие RPC полем `last_reviewed_at`. Она сохраняет старые стадии и позиции очереди. Примените миграцию перед публикацией нового клиента, чтобы даты проверок записывались в облако с первого использования.
