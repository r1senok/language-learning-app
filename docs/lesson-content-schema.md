# Схема контента уроков Takku

## Текущая модель

- [course.ts](../src/lessons/course.ts) содержит текущий `lessonId = 'tere-a1-01'`, каталог уроков и прежние задания для совместимости. [Lessons.tsx](../src/lessons/Lessons.tsx) открывает только первый урок.
- [readerContent.ts](../src/lessons/readerContent.ts) экспортирует `lessonSteps: ReaderStep[]` и отдельный список `lessonReferences: ReferenceContent[]`. Этап имеет `id, title, page`. `theory` получает `panels`, `practice` — `exercises` и опциональные `partStarts`. Упражнения поступают из `tereLessonContent.ts`, `pronounExercises.ts`, `greetingsContent.ts`.
- [engine.ts](../src/lessons/engine.ts) объявляет проверяемый union `Exercise`. Общие поля — `id, prompt, explanation, exampleAudio?, scene?`. Книжные метаданные `book` — `lessonId, number, question, total, page, heading, language` плюс опциональные `bookId, mode, answerSource`. `number` — номер упражнения в книге, `question` — его порядковый вопрос. Они не определяют номер части интерфейса.
- `word_intro` хранит каталоговый UUID, пару `et/ru`, необязательные строку форм и примечание. `multiple_choice` хранит варианты, ID правильного, необязательные допустимые ID и настройки подачи. `fill_blank` может задавать `sentence.before/after`. Исторический `book.mode: gap` маршрутизируется в тот же UI. `matching_pairs` хранит стабильный ID пары и тексты обеих колонок. `word_order` хранит токены и правильную последовательность ID.
- `ReferenceContent` содержит `id, title, exerciseIds, panels`. Тексты теории задаются строкой или упорядоченными сегментами, а внутри `ContentGroup` допускаются вложенные блоки. `DialogueLine.audioSrc` и `Question.exampleAudio` существуют как поля. Сам Reader пока не подсоединяет воспроизведение к этим шаблонам.
- Локальная запись `takku-lessons-v1:<user|guest>:<lessonId>` хранит контрольную точку. Облачное `lesson_results` хранит оценки по пользователю, уроку и ID задания. Импорт обязан сохранять уже опубликованные ID, в том числе ID вариантов, токенов и точек продолжения.

## Предложение для Book Studio

Ниже схема импорта, которую текущий Reader напрямую не читает. После ревью адаптер должен преобразовать опубликованные части в существующие типы. Исходник хранится рядом с учебной интерпретацией и остаётся доступным для сверки.

| Уровень | Поля предложения |
| --- | --- |
| Книга | `bookId`, название, издание, учебная пара языков |
| Урок | `lessonId`, `bookId`, позиция в книге, заголовок оригинала и перевод, упорядоченный `parts[]`, справочники |
| Часть | Стабильный `id`, позиция в упорядоченном списке, `template`, заголовок, `source`, `status: draft | review | published | deferred`, визуальные параметры |
| Источник | Страница или диапазон, номер книжного задания, исходная инструкция, ссылка на внутренний снимок / фрагмент, источник ключа ответов |
| Практика | `questions[]` в исходном порядке. У вопроса ID, точный текст, язык, варианты / пары / токены, ключи и переводы, дополнительные языковые или грамматические поля |
| Теория | `panels[]` с существующими типами блоков, сегментами, таблицами, ролями и переводами реплик. Сохранять исходный порядок блоков и смысловые группы |
| Ресурсы | Необязательный `audio` с источником, языком, привязкой к реплике или вопросу и статусом доступности / проверки |
| Ревью | Причина отложения, ссылка на подтверждение ключа, результат проверки доступности каталоговых UUID и ресурсов |

Пример будущей записи для **первого** вопроса №11. Варианты, текст и ключ взяты из текущих данных; это фрагмент конфигурации, в книге здесь шесть вопросов.

```json
{
  "bookId": "tere-a1",
  "lessonId": "tere-a1-01",
  "part": {
    "id": "olema-practice",
    "template": "fill_blank",
    "source": { "page": 15, "exercise": 11, "answerSource": "vastused-215" },
    "questions": [{
      "id": "exercise-11-1",
      "language": "et",
      "prompt": "Ma … õpetaja.",
      "sentence": { "before": "Ma ", "after": " õpetaja." },
      "options": [
        { "id": "olen", "text": "olen" },
        { "id": "oled", "text": "oled" },
        { "id": "on", "text": "on" },
        { "id": "oleme", "text": "oleme" },
        { "id": "olete", "text": "olete" }
      ],
      "correct": "olen",
      "referenceIds": ["tere-a1-01-olema-spikker"]
    }]
  }
}
```

Для уже опубликованного урока адаптер должен вернуть текущую группировку этапов и привязки шпаргалок. При отдельной части для №12 нужно заранее определить совместимость старой точки `olema-practice`. Для новых уроков порядок частей задаёт их массив, вопросы одной части не получают свои номера частей.

### Минимальная проверка перед публикацией

Проверять уникальность ID в уроке и их стабильность между ревизиями, ссылки на ответы, размерность таблиц, количество пропусков, полные пары и корректную длину порядка токенов. Подтверждать происхождение текста, исходный порядок, ключи и необходимые языки. Варианты, которых нет в самом задании, и адаптацию аудио или диалога отмечать для ручной проверки. Материал со статусом `deferred` сохранять рядом с источником и исключать из активного Reader. Не генерировать замену учебнику при отсутствии текста или ключа.
