# Импорт готовых MP3 в Takku

Пять файлов можно подготовить любым разрешённым способом. Скрипт работает с файлами на диске. Браузер Takku запрашивает готовый файл в Storage.

## 1. Подготовьте файлы

Положите MP3 в отдельную папку вне репозитория, например `~/Takku-MP3`.

| Имя файла | Текст |
| --- | --- |
| `tere.mp3` | Tere! |
| `tere-hommikust.mp3` | Tere hommikust! |
| `head-aega.mp3` | Head aega! |
| `ma-olen-opetaja.mp3` | Ma olen õpetaja. |
| `ma-ei-ole-opetaja.mp3` | Ma ei ole õpetaja. |

Лимит на файл — 1 МиБ. Каталог соответствий общий для импорта и приложения. Новое слово или предложение добавляется в него под уникальным стабильным ID. Регистр, пробелы, Unicode-представление и финальные точка или восклицательный знак нормализуются при поиске файла. Вопросительный знак сохраняется. Один текст использует один MP3 во всех разделах.

## 2. Подготовьте Supabase

В тестовом проекте откройте **Storage**. Если bucket `takku-tts` ещё отсутствует, создайте его через [миграцию](supabase/migrations/20261124010000_tts_storage.sql) в SQL Editor. Для чтения MP3 используется публичный URL. Миграция не выдаёт клиентам право записи. Если bucket уже есть и доступен для чтения MP3, повторно запускать миграцию не нужно.

Для локальной команды используйте серверный ключ Supabase с правом записи в Storage. Поместите его только в переменную `TAKKU_AUDIO_STORAGE_KEY` в своей оболочке. Ключ не должен попадать в GitHub, Vite или Cloudflare. Например, в стандартном Terminal macOS с zsh можно выполнить `read -s "TAKKU_AUDIO_STORAGE_KEY?Ключ Supabase: "; export TAKKU_AUDIO_STORAGE_KEY`. Ввод при этом скрыт.

## 3. Проверьте и загрузите

Из корня репозитория, с Node.js 24:

```bash
node scripts/import-prepared-audio.mjs "$HOME/Takku-MP3"
```

Без адреса это локальный dry-run. Он выводит соответствия, отсутствующие файлы и ошибки. Добавьте `--url https://PROJECT.supabase.co` для сверки с тестовым Storage без записи. Чтобы загрузить, выполните одну команду:

```bash
node scripts/import-prepared-audio.mjs "$HOME/Takku-MP3" --url https://PROJECT.supabase.co --upload
```

Команда пропускает существующие файлы и запрещает перезапись даже при одновременной загрузке. Если проверка исходных файлов обнаружит ошибки, загрузка не начнётся. Сетевой сбой во время записи может оставить часть партии загруженной. Повтор той же команды дозагрузит оставшееся. Для осознанной замены записи проверьте нужный объект в Dashboard и отдельно сохраните его резервную копию. После работы можно выполнить `unset TAKKU_AUDIO_STORAGE_KEY`.

Адреса файлов имеют вид `takku-tts/prepared/v1/tere.mp3`. Google TTS остаётся резервным генератором со своим каталогом в Storage. Его результат можно скачать и передать этому же скрипту как готовый MP3. В клиенте дополнительные переменные для поставщика не нужны.

## 4. Проверьте на iPhone

Откройте тестовую сборку ветки в Safari. Для её Cloudflare Preview укажите существующие публичные настройки тестового Supabase. В **Уроки → Hakkame pihta!** нажмите динамик у приветствий, затем проверьте два предложения в шаге про отрицание. Проверьте фразу вне пилота, например Tervist!. Если слово или фраза есть в тестовом словаре, её можно также проверить оттуда и в карточке изучения.

## Весь словарь и уроки через eSpeak NG

Для генерации нужны Node.js 24, eSpeak NG со встроенным голосом `et` и FFmpeg с libmp3lame. На Mac с Homebrew их можно установить командой `brew install espeak-ng ffmpeg`. Google API и рабочий сервер для синтеза не нужны.

Скрипт берёт эстонские леммы из JSON-снимка каталога и находит произносимые примеры в данных уроков. Для обновления словаря передайте свежий JSON-массив объектов с полем `lemma`. При необходимости можно добавить согласованное с редактором поле `spoken` для произношения сокращений. Лемма и адрес файла при этом сохраняются. Ограничение ключа — 180 байт нормализованного эстонского текста. Пять пилотных имён сохраняются. Остальные имена вычисляются из текста и совпадают в словаре, карточках и уроках.

Генерация и проверка MP3 без обращения в Supabase:

```bash
node scripts/prepare-estonian-audio.mjs --out "$HOME/Takku-MP3-full"
```

Скрипт записывает `manifest.json` с исходным текстом, произнесённым вариантом, источниками и SHA-256 каждого файла. Неизменные проверенные MP3 переиспользуются. Выходную папку храните вне Git. Существующие отличающиеся локальные MP3 защищены от перезаписи.

Готовый архив можно импортировать без eSpeak NG или FFmpeg. После распаковки перейдите в корень репозитория и проверьте файлы:

```bash
node scripts/import-prepared-audio.mjs "$HOME/Takku-MP3-full" --manifest
```

После проверки тестового bucket и настройки локального `TAKKU_AUDIO_STORAGE_KEY` добавьте `--url https://TEST_PROJECT.supabase.co --upload`. Сохранённые объекты пропускаются. При прерванной загрузке повторите ту же команду.

Для генерации и дозагрузки новых записей одной командой используйте:

```bash
node scripts/prepare-estonian-audio.mjs --catalog /path/to/vocabulary.json \
  --out "$HOME/Takku-MP3-full" --url https://TEST_PROJECT.supabase.co --upload
```

### Лицензия

Используется встроенный формантный голос eSpeak NG Estonian `et`, без MBROLA и сторонних голосовых пакетов. Движок распространяется под GPLv3. Согласно §2 лицензии результат работы подпадает под GPL только если его собственное содержимое является охраняемым произведением, покрытым лицензией. В Takku распространяются результаты синтеза учебного текста. Движок и голосовые данные не входят в архив или приложение. Права на исходные учебные тексты применяются отдельно.
