## Порядок запуска

1. В Supabase SQL Editor выполните весь [preview.sql](preview.sql). При исходных значениях ожидаются 80 готовых строк, 0 конфликтов и 0 записей. Предпросмотр работает в транзакции READ ONLY.
2. При любом конфликте остановитесь и проверьте detail. Для записи после подтверждения откройте отдельный запрос и вставьте [commit.sql](commit.sql). Он повторно сверяет актуальные значения и при конфликте блокирует всю партию.
3. После успешной записи сразу сохраните поле rollback_batch как отдельный JSON-массив. Порядок отката описан в [инструкции](../review/IMPORT.md). Для второй партии сохраните собственную копию rollback_batch; для отката используйте актуальный [import.sql](../import.sql).
