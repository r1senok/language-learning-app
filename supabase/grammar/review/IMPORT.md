# Импорт 527 записей через Supabase SQL Editor

1. Откройте **Supabase → SQL Editor → New query**. Вставьте весь [preview.sql](preview.sql) и нажмите **Run**. Предпросмотр запускается в транзакции READ ONLY. На исходном снимке ожидается 527 готовых строк, 0 конфликтов и 0 записей. Если часть этой партии уже применена, в сумме ready и already_applied должно быть 527. При любом конфликте остановитесь и проверьте detail.
2. После подтверждения предпросмотра откройте новый запрос и вставьте весь [commit.sql](commit.sql). Перед запуском подготовьте место для сохранения пакета отката. Запустите запрос один раз. Он сверяет UUID, леммы, русские переводы и оба исходных поля. При конфликте вся партия блокируется. Команда UPDATE меняет только part_of_speech и grammatical_forms.
3. После успешного завершения транзакции скачайте результат целиком, например через **Export → CSV**. Сохраните значение поля **rollback_batch** отдельно как JSON-массив без CSV-кавычек. Проверьте, что число объектов равно written и у каждого есть id и write_xid. Храните исходный пакет отдельно. Повторный запуск вернёт пустой пакет отката для уже применённых записей.
4. При необходимости отката откройте [шаблон import.sql](../import.sql), вставьте сохранённый массив в блок между разделителями `$grammar$` и замените режим на **rollback_preview**. После проверки результата переключите его на **rollback**. Если запись или перевод менялись после импорта, шаблон заблокирует откат всей партии.
